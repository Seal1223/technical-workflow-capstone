# Applied Project Workflow Map

## Homestead OS

Git and GitHub will preserve safe technical learning, architecture notes, implementation records, testing, recovery procedures, and selected sanitized portfolio evidence.

Sensitive network, security, family, property, credential, and operational information will remain private or local as appropriate.

Homestead OS requirements remain governed by the Homestead OS Charter and subordinate Homestead design documents.

## Options Trading Automation

Git and GitHub will support repository history, branches, issues, pull requests, testing, documentation, releases, and reproducible software and data workflows when substantive automation work begins.

The technical curriculum may improve implementation quality, but it does not define or validate trading strategy logic, assumptions, risk rules, or backtesting validity.

Trading-domain truth remains governed by the separate Options Trading / Strategy Enhancement project.

## EXFIL App

Git and GitHub will support application code, documentation, issues, branches, pull requests, testing, releases, and later CI/CD or deployment workflows when justified.

The technical curriculum does not define EXFIL's mission, product requirements, users, data-handling rules, feature priorities, or release decisions.

EXFIL-specific governing documents remain authoritative for those decisions.

## Common Workflow

ISSUE / REQUIREMENT
-> BRANCH
-> IMPLEMENT / DOCUMENT
-> TEST / REVIEW
-> COMMIT / PUSH
-> PULL REQUEST
-> MERGE
-> TAG / RELEASE WHEN MEANINGFUL
-> PRESERVE LESSONS / RECOVERY NOTES
