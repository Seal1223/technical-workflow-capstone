## Lessons Learned

Git provides local version control independently of GitHub, while GitHub adds remote hosting, collaboration, project tracking, review, and publishing capabilities.

A deliberate workflow makes it possible to experiment, review changes, recover from mistakes, and preserve a useful history of technical work.
