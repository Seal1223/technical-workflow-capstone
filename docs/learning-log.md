## Key Lessons

- Git provides local version control; GitHub provides remote hosting and collaboration.
- Local VS Code and Git are the primary working environment.
- GitHub should normally be synchronized with `git pull` before local work and `git push` after committed work.
- Branches isolate changes from `main`.
- Pull requests provide a review step before merging.
- Merge conflicts require deliberate resolution when Git cannot safely choose between competing changes.
- `.gitignore` helps prevent unwanted files from being tracked but is not a security boundary.
- Credentials committed to Git must be treated as compromised and rotated.
- A remote repository can recover committed and pushed history, but it is not a complete backup of all local project data.
